# Ma Biblio

Ma bibliothèque de mangas et webtoons : où j'en suis dans chaque série, ce qui est sorti depuis, et mes tomes papier.

- **Site** : https://lucasmpf1.github.io/ma-bibliotheque-manga/
- **Données** : la branche `data` contient `library.json` (ma liste et ma progression) et `releases.json` (les derniers chapitres sortis).
- **Nouveaux chapitres** : la tâche `.github/workflows/releases.yml` interroge MangaUpdates deux fois par jour.

Le site fonctionne sans installation : c'est une page web qu'on peut ajouter à l'écran d'accueil de l'iPhone (Safari → Partager → Sur l'écran d'accueil).
